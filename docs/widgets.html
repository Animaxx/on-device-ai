Widgets

Four widget families put the things you do most often one tap away: Listen, Voice Note, Text Note, and Quick Actions. Add them from the system widget gallery like any other widget. They are free.

Platforms

Widgets are available on iPhone, iPad, and Mac, including Home Screen, Lock Screen, and StandBy presentations where the family supports them. visionOS is not included. The Listen Library and RSS Feeds features themselves do work on Apple Vision Pro.

What each widget does

  • Listen: shows generic playback status, progress, and an active sleep-timer countdown when there is room. Its control resumes the paused current item, pauses the playing item, or claims and starts only the first item in Up Next. Later queue rows open Up Next in the app instead of playing out of order, and the widget cannot change the sleep timer.
  • Voice Note: opens Apple Speech creation and waits for you to press Record. It never starts recording on its own.
  • Text Note: opens a new note.
  • Quick Actions: a focused set of four entries — Play Next, RSS Feeds, Voice Note, and New Text Note.

Listen playback triggered from a widget uses authoritative app state and follows the normal app access policy, so anything that needs Pro inside the app still needs Pro from a widget.

Configure note widgets

Edit a medium Voice Note or Text Note widget to choose a maximum of one, two, or three recent notes and whether to show titles. The system can show fewer than your maximum when larger accessibility text or a longer language needs more room. Turning titles off replaces them with generic date metadata.

macOS open and record actions

On Mac, AI Voice Note keeps its open-only behavior: it opens creation and waits for Record. Record Voice Note is a separate menu action and configurable hotkey, Control-Shift-R by default. It starts recording only when the screen is ready, microphone and speech permissions already exist, and no conflicting voice capture is active. If a permission or capture conflict blocks it, the normal creation screen stays visible and recording never starts later behind a permission prompt. Hotkey customization follows the existing Pro policy.

Privacy and limits

  • Widgets render small read-only snapshots. They do not open your databases or run speech engines.
  • Recent note titles appear only in eligible medium Home Screen or macOS presentations, and only when you allow them. Small, Lock Screen, StandBy, and CarPlay-safe presentations never show user titles.
  • Widget links use a public allowlisted URL contract, and public URLs never start recording automatically.
  • Queue management stays in the app: reorder, remove, and mark-played actions are not widget operations.
  • A stale widget item opens the relevant list with an unavailable-item message instead of failing silently.
  • CarPlay interaction is limited without full in-car app integration.

Language

Widget labels follow the App Language you select inside On Device AI. Change it in settings, then let the system refresh the widget. If a selected language has no widget copy available, widgets fall back to English. Your own note, document, RSS, and source names are never translated.
