App Help

App Help is a focused help chat for questions about the app itself. Ask how a feature works or where a setting lives, and it answers using the model you already have active plus a bundled help guide that ships inside the app. Available on iPhone, iPad, Mac, and Apple Vision Pro, with no subscription gate.

Where to find it

Open Menu → App Help. A one-time announcement can introduce the feature, and a New marker stays in Menu until you open it. Opening App Help starts an empty temporary session: it does not send a question or change your model settings. To see the announcement again, use Settings → About → Reset Model Suggestions & App Help; that replay does not restore the New marker.

Remote inference hosts

App Help is unavailable while the app is connected to a remote inference host. Disconnect and use a local or configured model to ask a help question.

How it differs from AI Chat

  • Ephemeral: sessions live in memory only and are excluded from conversation history. New Session clears the transcript.
  • Text only, no tools: no attachments, tool calling, roles, user Knowledge Libraries, or editable system prompt.
  • Fixed instructions: App Help uses immutable product instructions and an immutable bundled English help corpus, with bounded retrieval of the relevant passages for your question.
  • Focused controls: only the conversation controls the help flow needs, not the full chat toolbar.
  • Your active model: answers come from whichever supported chat model you already have loaded.

Settings actions that App Help surfaces are trusted and read-only pointers to the relevant screen. App Help does not change your configuration for you.

What to ask

  • Feature explanations — "What is the difference between Listen Library and a Knowledge Library?"
  • Setting locations — "Where do I change playback speed?"
  • Workflow guidance — "How do I turn a scanned book into audio?"

App Help should distinguish verified bundled knowledge from its own suggestions, so you can tell documented behavior from a guess.

When it cannot answer

If App Help cannot find relevant product knowledge, rephrase the question using the feature or Settings name, check the matching in-app screen, or send reviewed feedback. Feedback is focused and shown to you before it is sent.

Privacy

Do not paste secrets or private document content into a help question — App Help does not need them to explain how the app works, and it keeps app knowledge internal rather than exposing your data. Diagnostic reports include the app version, hardware setup, and model engine logs; conversation text, prompts, and attachments are omitted.

English only

App Help content and answers are English-only. The app interface supports additional languages, but help questions and answers do not.
