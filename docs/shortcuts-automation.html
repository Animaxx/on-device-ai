Shortcuts and Automation

Use Siri and Shortcuts to open app content, create notes, transcribe audio files, and generate speech. Calendar and Reminders tools can help manage your schedule and tasks after you grant permission.

Siri and Shortcuts

On Device AI exposes shortcut actions for common workflows. In the Shortcuts app, search for On Device AI and choose the action that matches your task.

  • Create a Text Note with a title, content, and destination library
  • Open a saved conversation, Knowledge Library, or library document
  • Transcribe an audio file and return the text
  • Speak text aloud, export an audio file, or do both

Open App Content

Shortcuts can open saved app content by name or selection. This is useful for building personal workflows such as "open my meeting library" or "continue my planning conversation."

If the app is still loading your content, it waits until the selected item is available and then opens the right screen.

Speech Workflows

Use speech shortcuts when you want automation outside the app UI.

  • Transcribe audio: Pass an audio file and get text back. You can optionally choose a language or an available speech model.
  • Speak text: Send text to the active speech engine, export the generated audio file, or both speak and export.

If a requested model is not downloaded or requires access you do not have, the shortcut returns a clear message instead of silently switching to another choice.

Calendar and Reminders

Calendar and Reminders tools let the assistant read selected schedule or task information and propose changes. Use them for jobs like checking today's meetings, drafting a reminder, moving a task to another list, or creating a calendar event from a conversation.

Changes such as creating, updating, completing, moving, or deleting events and reminders require review before they run. If the request starts outside the app, the change waits for your approval.

Permissions and Privacy

Automation features use explicit permission steps:

  • Calendar and Reminders access require system permission
  • Personal-data tools stay off until you enable them
  • Changes to calendar or reminder data require approval before execution
  • If you use a cloud model or external chat integration, returned personal data may be sent to that selected provider or context

For private workflows, use local models and keep personal-data tools limited to the conversations where you need them.
